# 02 · Rakip Analizi

## 1. Rakip Haritası

Dört kategoriye ayırıyoruz: (A) doğrudan tür rakipleri, (B) mekanik rakipleri (yaş grubu farklı),
(C) model rakipleri (etik monetizasyon kıyası), (D) düşük kaliteli arama rakipleri.

### A. Doğrudan tür rakipleri (çocuk + yumurta/koleksiyon)

| Oyun | Durum | Güçlü yanı | Zayıf yanı / bizim fırsatımız |
|------|-------|-----------|-------------------------------|
| **Adopt Me!** (Roblox, Uplift Games) | Roblox'un en çok ziyaret edilen deneyimi; **40 milyar+ ziyaret**, 475K+ eşzamanlı oyuncu zirvesi | Yumurta çıtlatma → evcil hayvan → bakım → yaş büyütme → 4 aynı pet'i "Neon"a birleştirme: **kanıtlanmış çekirdek döngü.** Sürekli yeni yumurta temaları. | Roblox'a hapsolmuş (4 yaş için uygun platform değil), Robux ekonomisi + takas sistemi **dolandırıcılık ve "çocuk kumarı" eleştirisi** üretiyor; 8.000 AUD'lik çocuk harcaması gibi skandallar ebeveyn güvenini bitirmiş durumda. Ebeveynin güveneceği bağımsız alternatif yok. |
| **Hatchimals CollEGGtibles (uygulama)** (Spin Master) | 2017'de çıktı, **Mart 2020'den beri güncellenmiyor** (fiilen terk edilmiş) | 300+ karakterli koleksiyon evreni, fiziksel oyuncak entegrasyonu (Collector's Book), bakım + mini oyun + günlük çark formülü doğruydu | Ürün öldü. "Yumurta koleksiyonu" konsepti mobilde şu anda **sahipsiz.** Fiziksel-dijital köprü fikri (koleksiyon defteri) bizim faz-2 kart hattımızın ilham kaynağı. |
| **Pet Simulator 99 / Blox Fruits** (Roblox) | Çok popüler | Yumurta/rastgele ödül döngüsü güçlü | Aynı Roblox sorunları; akademik çalışmalarda çocukların kendisi bu oyunları *"literally just child gambling"* diye tanımlıyor. Bu algı, bizim "şans satmayan" konumumuzu keskinleştiriyor. |

### B. Mekanik rakipleri (koleksiyon/yumurta mekaniği, farklı kitle)

| Oyun | Ders |
|------|------|
| **Monopoly GO!** (Scopely) | Sticker albümü = modern Panini. Albüm → setler → set tamamlama ödülü → albüm tamamlama büyük ödülü → yeni albüm. Altın (nadir) stickerlar, takas etkinlikleri, "Sticker Boom" dönemleri. İlk yılında milyarlarca dolar gelir. **Albüm yapısını, set ödüllerini ve "tamamlama kutlamasını" alıyoruz; FOMO baskısını ve paralı paket rastgeleliğini almıyoruz** (albümleri süreyle yakıp yok etmek çocuk segmentinde kabul edilemez — bizde eski koleksiyonlar "Müze"ye taşınır, yakılmaz). |
| **Pokémon GO** (Niantic) | Yumurta = **mesafe/emekle** açılır (2/5/10 km). Para kuluçka makinesi satar ama yumurtanın kendisi emek ister. "Emeğin açtığı yumurta" hissi bizim modelin atası. Ayrıca kanıt: yumurta içeriği havuzlarının şeffaf yayınlanması güveni artırıyor. |
| **Pokémon TCG / Panini** | Fiziksel koleksiyonun sosyal katmanı (takas, gösterme) çok güçlü; ama çocuklar arası takas dolandırıcılığa açık → bizde takas yerine **tek yönlü hediye** (Bölüm 07). |

### C. Model rakipleri (etik monetizasyon kıyası — aynı zamanda ilham)

| Ürün | Model | Ders |
|------|-------|------|
| **Toca Boca World / Piknik** | Abonelik + deterministik içerik paketleri, reklamsız | Çocuk segmentinin gelir şampiyonu (1 milyar $+ toplam, zirvede 17M$/ay). "Şans satmadan" bu tavana ulaşılabiliyor. Piknik aboneliği (Toca+Sago+Originator tek pakette) → bizim "Yuvo Club" için şablon. |
| **Applaydu** (Ferrero/Kinder + Gameloft) | Tamamen ücretsiz, satın almasız, reklamsız; Oxford Üniversitesi LiFT araştırma iş birliği; 4–9 yaş; 18 dil | Kinder'ın kendisi "çikolata satarım, uygulama pazarlama+eğitim aracıdır" diyor. **Bizim farkımız:** Applaydu bir marka uzantısı, derin koleksiyon meta-oyunu yok. Ama çıtası önemli: ebeveyn iletişimi, akademik iş birliği, güvenlik sertifikaları. Ayrıca AR ile fiziksel oyuncağı canlandırma fikri not edilmeli. |
| **Sago Mini World** | Abonelik | Okul öncesi segmentte abonelik kabulünün kanıtı. |

### D. Arama rakipleri (ASO)

"Surprise eggs" aramasında çıkan onlarca uygulama (Kauf, ideaMK, Dobermann Studios vb.):
tek mekanikli (kazı/aç), reklam yağmurlu, koleksiyonsuz, markasız. Yıldız puanları orta,
yorumlar "reklam çok" şikâyeti dolu. **ASO stratejisi:** bu aramanın hacmini kaliteyle topla;
"no ads, no gambling" rozetini mağaza metninin ilk cümlesi yap.

## 2. Boşluk Analizi (Positioning Map)

```
                    Derin koleksiyon meta-oyunu
                              ▲
                              │
             Adopt Me ●       │       ★ YUVO (hedef)
        (güven sorunu,        │   (güven + derinlik)
         Roblox'a bağlı)      │
                              │
 Ebeveyn ◄────────────────────┼────────────────────► Ebeveyn
 güveni düşük                 │                      güveni yüksek
                              │
   "Surprise egg" ●           │        ● Applaydu / Toca Boca
   çöp uygulamalar            │       (güvenli ama koleksiyon
                              │        derinliği yok)
                              ▼
                    Sığ / tek mekanikli
```

**Boş kadran:** yüksek ebeveyn güveni + derin koleksiyon oyunu. Yuvo'nun yeri burası.

## 3. Rakiplerden Alınan / Reddedilen Mekanikler Özeti

| Mekanik | Kaynak | Karar |
|---------|--------|-------|
| Yumurta → yaratık → bakım → birleştirme | Adopt Me | ✅ Al (Neon birleştirme → bizde "Işıltılı Pufi", Bölüm 07) |
| Albüm/set/tamamlama ödülü | Monopoly GO, Panini | ✅ Al |
| Emekle açılan yumurta | Pokémon GO | ✅ Al (mesafe yerine oyun görevi) |
| Koleksiyon defteri + fiziksel oyuncak köprüsü | Hatchimals | ✅ Al (faz 2) |
| Günlük çark / login ödülü | Hatchimals | ⚠️ Dönüştür: login ödülü değil, "günlük görev zinciri" (Bölüm 08) |
| Robux benzeri ara para birimi | Roblox | ❌ Reddet (fiyat gizleme = dark pattern) |
| Paralı rastgele yumurta/paket | Adopt Me, Monopoly GO | ❌ Reddet (loot box; yasal risk + etik ihlal) |
| Çocuklar arası serbest takas | Adopt Me | ❌ Reddet (dolandırıcılık vektörü) → tek yönlü hediye |
| Süreli albüm yakma (bitince koleksiyon silinir) | Monopoly GO | ❌ Reddet → "Müze" sistemi |
| FOMO sayaçları, "son X saat!" baskısı | Sektör geneli | ❌ Reddet |
